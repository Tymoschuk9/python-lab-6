# Лабораторна робота №6
## Тема: Автоматизоване тестування Python-програм (pytest)
## Мета роботи
Метою лабораторної роботи є освоєння технік автоматизованого тестування Python-програм за допомогою фреймворку pytest, включаючи використання моків, асинхронних тестів та інтеграційних тестів.

## Опис алгоритму та архітектури (Варіант №3)
У даній лабораторній роботі реалізовано систему інтернет-магазину, яка включає класи для представлення товарів, кошика, знижок, процесу оплати та повідомлень. Основні класи включають `Money`, `Product`, `CartItem`, `Cart`, `PercentageDiscount`, `PaymentGateway`, `Notifier`, `CheckoutService`, `export_order`, `get_payment_mode`, та `AsyncPaymentStatus`.

## Опис реалізованих функцій та класів
- `Money`: Представляє грошову суму з валютою.
- `Product`: Представляє товар з ідентифікатором, назвою та ціною.
- `CartItem`: Представляє товар у кошику з кількістю.
- `Cart`: Представляє кошик з можливістю додавання товарів та розрахунку загальної суми.
- `PercentageDiscount`: Реалізує знижку у відсотках.
- `PaymentGateway`: Симулює процес оплати.
- `Notifier`: Симулює повідомлення.
- `CheckoutService`: Реалізує процес оформлення замовлення.
- `export_order`: Експортує замовлення у JSON файл.
- `get_payment_mode`: Повертає режим оплати.
- `AsyncPaymentStatus`: Симулює асинхронний процес отримання статусу оплати.

## Результати виконання програми
Програма успішно тестує всі функціональності інтернет-магазину, включаючи додавання товарів до кошика, розрахунок загальної суми, застосування знижок, процес оплати та експорт замовлення. Всі тести пройшли успішно.

## Висновки
Лабораторна робота демонструє ефективне використання pytest для автоматизованого тестування Python-програм. Використання моків та асинхронних тестів дозволяє перевірити роботу системи в різних сценаріях, включаючи обробку помилок та інтеграційні тести.
