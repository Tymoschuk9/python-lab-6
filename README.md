# Лабораторна робота №6
## Тема: Автоматизоване тестування Python-програм
### Варіант: 3 (Інтернет-магазин)

### Опис проєкту:
Проєкт містить повноцінний набір автоматизованих тестів для системи інтернет-магазину:
- Модульні тести (unit tests): перевірка моделей `Product`, `Money`, `Cart`, знижок `PercentageDiscount` та сервісу оформлення `CheckoutService`.
- Мокування залежностей: використання `unittest.mock.Mock` та `AsyncMock` для платіжного шлюзу, сервісу сповіщень та асинхронного постачальника.
- Конфігурація: тестування параметрів конфігурації за допомогою `monkeypatch`.
- Інтеграційні тести: перевірка файлового імпорту/експорту за допомогою `tmp_path`.
- Аналіз покриття коду: налаштовано `pytest-cov` із перевіркою branch coverage.
