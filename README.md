# Лабораторна робота №6
## Тема: Автоматизоване тестування Python-програм (pytest)
## Мета роботи
Метою лабораторної роботи є освоєння методів автоматизованого тестування Python-програм за допомогою фреймворку pytest, включаючи використання фікстур, моків та асинхронного тестування.

## Опис алгоритму та архітектури (Варіант №3)
У даній лабораторній роботі реалізовано систему інтернет-магазину, яка включає класи для роботи з грошовими сумами, продуктами, кошиком, знижками, процесом оформлення замовлення та експорту замовлення у файл. Також реалізовано асинхронний функціонал для отримання статусу платежу.

## Опис реалізованих функцій та класів
- **Money**: Клас для роботи з грошовими сумами, включає операції додавання та множення.
- **Product**: Клас, що представляє продукт з ідентифікатором, назвою та ціною.
- **CartItem**: Клас, що представляє товар у кошику з кількістю.
- **Cart**: Клас для роботи з кошиком, включає методи додавання товару та розрахунку загальної суми.
- **PercentageDiscount**: Клас для застосування процентної знижки до суми.
- **PaymentGateway**: Клас для симуляції процесу оплати.
- **Notifier**: Клас для симуляції сповіщення.
- **CheckoutService**: Клас для оформлення замовлення, включає оплату та сповіщення.
- **export_order**: Функція для експорту замовлення у файл JSON.
- **get_payment_mode**: Асинхронна функція для отримання режиму оплати.
- **AsyncPaymentStatus**: Клас для асинхронної перевірки статусу платежу.

## Результати виконання програми
Програма успішно тестує всі реалізовані функції та класи, включаючи асинхронний функціонал. Результати тестів показують коректну роботу всіх компонентів системи.

## Висновки
Лабораторна робота дозволила освоїти методи автоматизованого тестування Python-програм за допомогою pytest, включаючи використання фікстур, моків та асинхронного тестування. Реалізована система інтернет-магазину демонструє коректну роботу всіх компонентів та є готовою до подальшого розширення та вдосконалення.
